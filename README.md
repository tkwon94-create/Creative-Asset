# Creative-Asset

Claude Code skills for ad creative production.

## Installed skills

### [winning-statics](.claude/skills/winning-statics/SKILL.md)

Recreates proven, high-performing static image ads for your product. It takes 50 real
winning statics — captured from live ad libraries with their performance receipts,
organized into 9 concept families — and replicates their structure, hierarchy, and
psychology with your product, brand colors, copy angle, and market, using Google's
Nano Banana Pro image model — via your own Google API key or your Higgsfield plan.

- **Setup (one time, pick one):**
  [HIGGSFIELD_SETUP.md](.claude/skills/winning-statics/HIGGSFIELD_SETUP.md) or
  [GEMINI_SETUP.md](.claude/skills/winning-statics/GEMINI_SETUP.md)
- **Reference library:** [catalog.md](.claude/skills/winning-statics/references/catalog.md)
- **Use it:** open Claude Code in this repo and say something like
  *"make me 20 statics for my product"*.
